=== PROJECT: Villa Azure Resort ===

1. PROJECT NAME & PURPOSE
Villa Azure Resort is a private resort web application. Current phase
scaffolds the VISITOR master template (public-facing site) first, with
a SUPER ADMIN account to be scaffolded next. The visitor site follows
the section order defined in the resort visitor master template plan:
Hero, About, Rooms & Villas, Amenities, Resort Shop (browse-only, no
cart/checkout), Activities/Experiences, Gallery, Testimonials, Location,
Contact/Inquiry, Footer. Events & Functions and Spa & Wellness are
intentionally left out for now.

Progress: Hero (done), About (done). Next: Rooms & Villas.

2. TECH STACK
- Next.js 16.2.x (App Router, Turbopack)
- JavaScript (no TypeScript)
- React 19.2.x
- CSS Modules / plain CSS (no Tailwind)
- axios (installed, for client-side calls to external APIs)
- Backend service: not yet connected (Supabase planned per Fixed Services Standard)

3. ACCOUNT TYPES
- visitor    — public, no auth required (scaffolded)
- superAdmin — protected, auth required (not yet scaffolded)

4. DATABASE OVERVIEW

6. PROCESS FLOW

=== PROCESS: Visitor Homepage Render ===
Step 1 : Visitor hits "/visitor"
Step 2 : app/visitor/layout.jsx wraps the page, imports Visitor.css
Step 3 : app/visitor/page.jsx (Server Component) renders <Hero /> then <About />
Step 4 : components/Hero.jsx renders static resort name, tagline, and two CTAs
Step 5 : "Plan Your Stay" anchors to #contact, "Explore Rooms & Villas" anchors to #rooms
         (both sections do not exist yet — added later per the master template plan)
Step 6 : components/About.jsx renders the resort story and a 3-card
         "why choose us" grid, with id="about" as the anchor target
Step 7 : components/Hero.jsx renders a placeholder background photo via
         next/image (Unsplash, free to use) layered under a dark gradient
         overlay for text contrast — swap for real resort photography in
         public/images/ once Cloudflare R2 is connected

7. FILE MAP
- app/layout.jsx              — root layout shell, global metadata, imports globals.css
- app/page.jsx                 — root route, redirects to /visitor
- app/styles/globals.css       — CSS design tokens (color, spacing, z-index, transitions) + reset
- app/styles/mediaQueries.css  — empty, ready for breakpoints
- middleware.js                 — auth guard shell, matcher currently covers /superAdmin only
- next.config.mjs             — remotePatterns allows next/image to load
                                Unsplash placeholder photos (images.unsplash.com)
- app/visitor/layout.jsx        — visitor account shell, public
- app/visitor/page.jsx          — visitor homepage, renders <Hero />
- app/visitor/Visitor.css       — visitor account-level styles
- components/Hero.jsx           — Hero section: resort name, tagline, two CTAs
- components/Hero.css           — Hero section styles, gradient background (no photo yet)
- components/About.jsx          — About section: resort story + 3 "why choose us" cards
- components/About.css          — About section styles, auto-fill differentiator grid
